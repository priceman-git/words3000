# 3000 слов — веб-версия (+2000 слов курса 2)

Аналог iOS-приложения «3000 слов» (Konstantin Neliubin): 3000 самых частотных английских слов,
300 уроков по 10 слов, один урок в день, проверка после каждых 5 уроков.
Работает в Safari на iPhone, iPad и Mac, ставится на экран «Домой» как приложение и работает офлайн.

## Как устроен урок

Полная спецификация — в [TZ.md](TZ.md). Кратко:

- **Главный экран.** Сверху уровень, профиль и число выученных слов. Ниже страницы по 50 уроков.
  В ряду 4 урока и проверочный тест со звёздами.
- **Урок из 6 этапов**, строго по порядку:
  1. **Изучение** — «Знаю слово» или «Выучить слово».
  2. **Запоминание** — выбор перевода из 4 вариантов.
  3. **Повторение** — пары слово ↔ перевод.
  4. **Аудирование** — собрать слово из букв на слух.
  5. **Написание** — собрать слово из букв по переводу.
  6. **Закрепление** — набрать слово на клавиатуре.
- **Баллы.** За слово в каждом упражнении до 3 баллов. Подсказка и неверная буква отнимают по баллу.
  Этап, пройденный с ошибками, пересдаётся только по незасчитанным словам.
- **Повторение урока.** После урока его можно активировать, оно открывается через 24 часа.
  Это «Закрепление» по всем словам урока, пока все не будут написаны верно.

## Словарь

`words.js` генерируется скриптом `build_words.py` из `data/*.txt` (формат `english|перевод`).
Транскрипции (`data/ipa.tsv`, американское произношение по [CMUdict](https://github.com/cmusphinx/cmudict)) и примеры фраз
(`data/examples.tsv`, англо-русские пары из [Tatoeba](https://tatoeba.org), CC BY 2.0 FR) готовит `enrich.py`.
Слова упорядочены по современной частотности: [wordfreq](https://github.com/rspeer/wordfreq) (CC BY-SA 4.0; Википедия,
субтитры, новости, книги, Reddit, Twitter, до ~2021 г.) и [SUBTLEX-US](https://www.ugent.be/pp/experimentele-psychologie/en/research/documents/subtlexus)
(американские субтитры, с частями речи; свободно для некоммерческого использования). Место слова — среднее геометрическое
мест в двух списках; формы сведены к базовым словам по [lemma.en](https://github.com/skywind3000/lemma.en).
Главное значение омографов (back — «назад», like — «как») — по SUBTLEX-US, список в `data/primary.txt`.
Базовая бытовая лексика (числа, цвета, еда, одежда…) из `data/freq/core.txt` включена обязательно.
Исходные списки `data/freq/subtlex_us_pos.tsv`, `wordfreq_en.tsv` и `lemma.txt` в репозиторий не входят
(лицензия SUBTLEX-US и размер); они нужны только для пересортировки слов. Готовый порядок зафиксирован в `words.js`
и `data/freq/course1.txt`, поэтому правка переводов работает и без них.
Чтобы поправить перевод, отредактируйте строку в `data/*.txt` и выполните:

```bash
python3 build_words.py
```

## Как установить на iPhone / iPad / Mac

Приложению нужен адрес в интернете с HTTPS. Бесплатные варианты:

**Netlify Drop (проще всего, 1 минута):** откройте https://app.netlify.com/drop и перетащите папку `words3000`.
Получите ссылку вида `https://….netlify.app`.

**GitHub Pages:** создайте репозиторий, загрузите содержимое папки, затем Settings → Pages → Deploy from branch.

Затем на каждом устройстве:

- **iPhone / iPad:** откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Mac:** Safari → «Файл» → «Добавить в Dock» (macOS Sonoma и новее) или просто закладка.

**Только в домашней сети, без публикации:** на Mac запустите сервер и откройте `http://<IP-адрес-Mac>:8765` на iPhone.
Офлайн-режим в этом случае работать не будет, потому что нет HTTPS.

```bash
python3 -m http.server 8765 --directory words3000
```

## Прогресс

Хранится на каждом устройстве отдельно (localStorage). Перенос между устройствами: «Профиль» → «Сохранить прогресс в файл».
Затем на другом устройстве: «Загрузить прогресс из файла» (через iCloud Drive или AirDrop).
Начать можно с любого урока: нажмите на его номер на главном экране.

## Офлайн-работа

Приложение не обращается к интернету: шрифт Roboto Condensed лежит в `fonts/` (SIL Open Font License 1.1),
словарь, примеры и транскрипции — в `words.js`, озвучка — встроенными голосами устройства.

- Service worker (`sw.js`) кэширует все файлы при первом открытии и дальше запускает приложение **из кэша**
  (мгновенно, без сети и при плохой связи). Работает только по **HTTPS** (или на localhost).
- Новая версия скачивается в фоне целиком и включается при следующем открытии.
- **Выпуск новой версии:** увеличить `V` в `sw.js` и номер `?v=` у `fonts/fonts.css`, `styles.css`, `words.js`, `app.js`
  в `index.html` — иначе установленные копии продолжат показывать старую версию.
- На iPhone добавьте приложение на экран «Домой»: Safari может удалить данные сайта, который не открывали 7 дней,
  приложения с экрана «Домой» это правило не затрагивает. Прогресс стоит периодически сохранять в файл (профиль).
